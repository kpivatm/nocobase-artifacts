# Module: KPI

Artifact cho phân hệ KPI trên NocoBase.

## Thứ tự apply

1. `collections/` — Apply data model trước (collection schema)
2. `blueprints/` — Apply page/block blueprints sau
3. `js-blocks/` — Bundle và upload custom JS blocks

## Dependency

- Core NocoBase >= 0.21
- Không phụ thuộc phân hệ khác (standalone module)

## Artifacts hiện có

_Chưa có artifact nào được export. Xem hướng dẫn export tại `scripts/export.sh`._
